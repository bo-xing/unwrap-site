1. 适用范围与联系方式

本政策适用于 iPhone 和 iPad 上的 Unwrap App 及本产品网站。如有隐私问题或相关请求，请通过 boxing.support@gmail.com 联系 Unwrap 开发者。

2. 文件与压缩包处理

压缩包的打开、预览、压缩与解压均在设备本地完成。Unwrap 不会将压缩包内容或压缩包密码发送给开发者。App 在你选择文件、分享文件给 Unwrap，或通过系统界面授权访问时读取相关文件。预览、导入和压缩包操作可能在设备上生成临时工作文件。

3. 本地设置与存储

Unwrap 在本地保存设置和功能所需信息，例如语言与外观偏好、最近使用的压缩包引用、文件夹访问书签、文件名编码选择和购买权益状态。主 App 与分享扩展使用共享容器传递你选中的文件和偏好。这些记录不会发送给开发者。保存在 App 的 Unwrap 文件夹中的压缩包可通过系统「文件」访问。删除 App 会删除其自身存储，包括该文件夹；请先将要保留的文件移至其他位置。

4. 系统服务与文件提供程序

如果你选择 iCloud 云盘、网络位置或第三方文件提供程序，相应服务会依据其设置和隐私政策处理文件存储与传输。Apple 的照片选择器会提供你选中的照片或视频。通知在你允许后用于本地操作状态提示。你可以在系统设置中管理权限。设备备份与操作系统诊断由你的 Apple 设置及 Apple 服务控制。

5. App 内购买

Unwrap Pro 通过 Apple App Store 购买，付款信息由 Apple 处理。Unwrap 使用 StoreKit 的交易与权益信息解锁 Pro 并恢复购买。开发者不会通过 App 收到你的银行卡信息。Apple 对相关处理适用其购买条款与隐私政策。

6. 你主动发送的支持信息

如果你向支持邮箱发送邮件，我们会收到你的发件地址，以及你主动提供的内容和附件。这些信息用于回复请求、排查相关问题；邮件由我们的邮件服务提供商处理。请避免发送密码、私人压缩包或其他不必要的个人信息。我们仅在处理支持、解决相关问题及履行适用义务所需的期间内保留通信记录。你可以要求删除支持邮件；法律要求保留的信息可能需要继续保存。

7. 网站访问

本网站不使用分析脚本、广告、追踪 Cookie、第三方字体或社交嵌入组件。网站托管于 GitHub Pages。GitHub 会出于安全目的记录访问者 IP 地址，并可能根据 GitHub 隐私声明处理服务数据。这类托管处理与 Unwrap App 的本地压缩包处理相互独立。访问外部链接时，适用目标服务的隐私政策。

8. 你的选择

你可以通过系统「文件」删除文件，在 Unwrap 设置中清理可清理的临时存储，管理系统权限，或删除 App。位于 App 自身存储之外的文件，包括云端文件，需要在相应位置管理。如需查询或删除你主动发送给支持邮箱的信息，请联系我们。

9. 政策更新

当 App、网站或相关做法发生变化时，我们可能更新本政策。最新版本及更新日期会发布在本页面。
